## Architecture context (short)

The Milk Depot roaster uses three K-type probes (Bean, Exhaust, Flame) feeding an Arduino Nano 5V via three of these breakouts on a stripboard. A dedicated NCP1117ST33T3G LDO supplies 3.3V to the breakouts from the stripboard; SPI is level-shifted by resistor dividers (SCK 1k/1.8k shared, CS 10k/18k per channel). Shields terminate at the probe end only. See `kicad-coffee-roaster` tool repo `RESUME.md` for the full locked spec.

## KiCad 10 Eagle import — step-by-step

The import is a KiCad GUI operation; `kicad-cli` has no Eagle import in v10.0.1.

### 1. Launch KiCad and run the import

```bash
kicad   # or GDK_BACKEND=x11 kicad  if Wayland decoration clips dialogs
```

In KiCad's project manager:

1. **File → Import → Non-KiCad Project → Eagle**
2. Select source: `breakout-max31855/eagle-source/SparkFun_Thermocouple_Breakout.sch`
3. Select destination: `breakout-max31855/` (same folder as this README)
4. Project name: `breakout-max31855`
5. Click **Import**

KiCad will generate `breakout-max31855.kicad_pro`, `.kicad_sch`, `.kicad_pcb` (and possibly `.kicad_sym` / `.pretty/` for unmapped symbols/footprints).

### 2. Tell Claude to run phase-2 cleanup

Once the import finishes, return to the `kicad-coffee-roaster` tool session and say "import done, run phase 2" — Claude will:

- Set the title block (title, company, author, revision, date, comments with licence & attribution)
- Set page size to **A4 landscape**
- Link the shared custom library (`../libs/milk-depot.kicad_sym` + `../libs/milk-depot.pretty`) via the project's `sym-lib-table` / `fp-lib-table`
- Run `kicad-cli sch erc` as a post-import sanity check

## Planned forks from upstream (5 changes)

Tracked as the "design deltas" from SparkFun DEV-13266. Each is a separate working session after phase-2 cleanup completes.

- [ ] **1. Footprint swap** — MAX31855K generic → **MAX31855KASA+** (genuine Maxim SOIC-8) using the symbol in `../libs/milk-depot.kicad_sym`.
- [ ] **2. Thermocouple connector** — Replace SparkFun's `PCB_THERMOCOUPLE` pads with **DG127-5.08-02P** (Mantech 15M0713) 2-pole 5.08 mm screw terminal. Verify pin 1 orientation against Degson datasheet.
- [ ] **3. Passive upsize** — 0603 → **0805** throughout (matches DigiKey #122880837 stock convention). C1 100 nF X7R, C2 10 nF X7R, L1/L2 470 Ω @ 100 MHz, R1 10 kΩ.
- [ ] **4. DNP footprints** — Add (do-not-populate by default):
  - C3, C4 (1 nF X7R 0805) — T+/T− common-mode caps
  - D1, D2 (5.6 V bidirectional TVS, SMA/SMB) — ESD/surge clamp at screw terminal
  - M3 chassis-bond mounting hole: 10 nF Y1 cap + 1 MΩ bleed resistor (both DNP for soft-bond option at bring-up)
- [ ] **5. Silkscreen + title block** — Board ID, attribution, licence, polarity warnings per locked spec:
  - `MD-TC-BRK v1.0`
  - `CC-BY-SA 4.0 / fork of SparkFun MAX31855K`
  - `Red = NEGATIVE` next to DG127 terminal
  - `+` / `−` markers on DG127 pads
  - `3.3V ONLY` next to VCC pin on JP1 header
  - Pin 1 dot on U1, JP1, J1

## Mechanical targets

- Screw terminal J1 on one long edge, 6-pin header JP1 on the opposite long edge, 20–25 mm apart.
- Preserve SparkFun's JP1 pinout exactly: `GND, VCC, SCK, MISO, NC, CS` — this keeps compatibility with SparkFun's reference wiring diagrams and any DEV-13266 sockets on the stripboard.
- 4× unplated M3 mounting holes (check clearance against the DG127 body and U1).
- Target PCB: 2-layer, JLCPCB-standard (6 mil/6 mil trace/space, 0.3 mm via).
